# Liora DevOps Platform

A cloud-native DevOps portfolio project using FastAPI, Docker, Kubernetes (k3s), GitHub Actions, Argo CD, Terraform, Ansible, Prometheus, and Grafana.

> Work in progress. Phase 1 establishes the FastAPI application, automated tests, Docker image, and GitHub Actions CI.

## Project objectives

- Build and test a containerized API.
- Publish images to GitHub Container Registry (GHCR).
- Provision infrastructure with Terraform and configure servers with Ansible.
- Deploy separate development and production environments on k3s using Argo CD.
- Monitor and secure the application and practice recovery procedures.
